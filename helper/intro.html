ONE LAST CHECK

最后，确认桌面端已运行。

打开 设置 → 桌面状态栏，查看「桌面端」卡片。首次启用会自动下载运行依赖并启动；若尚未就绪或安装失败，在按钮可用时点击 安装并启用，等待下载、校验及启动完成。出现 运行中、桌面运行依赖显示 已就绪，即表示桌面助手已启动。

安装前提：需公司网络、相应 GitLab 权限，以及本机 Git 仓库访问能力。运行边界：当前支持 Windows x64 / arm64，浮窗出现在运行 DSH 的宿主电脑，而非远程浏览器所在电脑。插件默认自动启动，缺少运行时会后台下载；失败时可在设置中点击「安装并启用」重试。安装与更新是否需要重启，以 DSH 的操作结果为准。

再了解一点。

网页演示和真正的桌面插件，有什么区别？

演示复用真实浮窗与通知的 HTML，但会话和接口均为模拟。系统级拖动、窗口置顶、托盘、真实通知位置与会话跳转，需要在 Windows 桌面端使用；网页不会执行这些操作。

通知会一直留在桌面上吗？

任务完成通知默认显示 10 秒，可选 5、10、15、30、60 秒，或不自动消失。待确认通知遵循待确认逻辑。时长修改只对新通知生效，不重新计时已有通知。

停用或更新，会清掉我的偏好吗？

用户设置与插件安装目录分离。正常更新、重启、重置位置或最小化到托盘不会清除单行 / 卡片形态偏好。停用不会删除运行时与用户设置。
